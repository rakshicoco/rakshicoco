RAKSHI COCO ERP — ANDROID APK FIRST ARCHITECTURE
================================================

IMPORTANT CHANGE OF PRIORITY:

The primary deliverable for this project is NOT a desktop website.

The PRIMARY PRODUCT is an ANDROID APPLICATION / APK.

The existing Next.js + Supabase architecture should be preserved where practical, but the entire application must now be developed with an Android-first, mobile-first product strategy.

Do NOT throw away the existing work.

Do NOT rebuild the ERP from scratch unless technically necessary.

The target architecture is:

Android APK
    ↓
Capacitor Android wrapper
    ↓
Next.js App Router web application
    ↓
Supabase Auth
    ↓
PostgreSQL + RLS
    ↓
Supabase Storage

The same application may remain usable in a browser, but Android APK is the primary target.
