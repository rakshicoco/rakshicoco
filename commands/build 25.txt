============================================================
RECYCLE BIN RULES
============================================================

When user deletes an eligible record:

1. Do NOT hard delete.
2. Set deleted_at = now()
3. Set deleted_by = authenticated user.
4. Set scheduled_delete_at = now() + 90 days.
5. Create audit log entry.
6. Remove from normal list queries.
7. Move it into Recycle Bin.

Recycle Bin page:

/dashboard/recycle-bin

Display:

Entity
Name / ID
Deleted by
Deleted date
Permanent deletion date
Days remaining
Original status

Actions:

Restore
Delete Permanently

Restore:

deleted_at = NULL
deleted_by = NULL
scheduled_delete_at = NULL

Create audit event:

RESTORED_FROM_TRASH

Permanent delete:

ONLY allowed when safe.

Before permanent deletion verify:

No dependent records
No stock references
No financial references
No invoice/payment references
No foreign-key dependencies
No audit history dependency.

If the record cannot safely be hard deleted:

retain it as ARCHIVED/VOIDED instead.

Never break referential integrity.
